#    Como um programa de usuário consegue fazer I/O sem executar

Resposta 1:
Para que o programa de usuário possa fazer operações de I/O, ele deve fazer uma solicitação ao sistema operacional, sendo essa solicitação a chamada de sistema(syscall).
